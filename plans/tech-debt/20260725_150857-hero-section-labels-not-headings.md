# hero-section-labels-not-headings

## Finding
Section labels ("Tips for saying thanks", "What's new") in the new hero box render as styled `<p>` elements, not `<h2>/<h3>`, so they're invisible to screen-reader heading navigation despite visually reading as section headers. (Standards)
