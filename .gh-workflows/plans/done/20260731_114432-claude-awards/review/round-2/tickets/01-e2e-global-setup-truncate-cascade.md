# 01 — Fix `global-setup.ts`'s TRUNCATE to use CASCADE

**What to build:** `apps/e2e/global-setup.ts`'s `truncateLikesTable()` function (around line 27) runs `"TRUNCATE TABLE likes;"` before every e2e run. Since the awards feature added the `like_awards` table with an FK referencing `likes.id` (migration `apps/api/drizzle/0003_nice_sir_ram.sql`), Postgres now rejects a plain truncate of `likes` with "cannot truncate a table referenced in a foreign key constraint," blocking `globalSetup` entirely and preventing every single e2e test from running (0 of 22+ tests execute). Change the statement to `"TRUNCATE TABLE likes CASCADE;"` — matching the exact fix already applied in `apps/api/src/apps/likes/likes.spec.ts`'s `GET /likes/stats` block (`await appPool.query("TRUNCATE TABLE likes CASCADE")`, line 331).
